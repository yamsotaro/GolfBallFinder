# External TestFlight beta source notice

Use this text only after both URLs are publicly reachable while signed out. It is intended for TestFlight beta
description/review information; no new in-app UI is required for this release-preparation change.

https://github.com/yamsotaro/GolfBallFinder

このビルドで使用する学習済みモデル、SHA256、由来、評価情報:
https://github.com/yamsotaro/GolfBallFinder/releases/tag/public-mvp-v4

## English

GolfBallFinder is an early beta that processes camera frames on-device and does not automatically upload images to
a cloud service. Source code is available under GNU AGPL v3 at:
https://github.com/yamsotaro/GolfBallFinder

The trained model used by this build, its SHA256, provenance, and evaluation information are available at:
https://github.com/yamsotaro/GolfBallFinder/releases/tag/public-mvp-v4

Third-party licenses and dataset attribution are recorded in `THIRD_PARTY_NOTICES.md` and `training/` in the source
repository. This beta is for initial accuracy evaluation and does not guarantee detection correctness.
